What would be removed from Lineage and Notes before they go on the site: taper and uploader names and handles, email addresses, links, and tracker or fan-site names. The technical chain stays. Nothing has changed yet — this page only shows what the rules would do.

Everything shown is removed by default. Where a rule got it wrong (it removed equipment, a broadcaster or something harmless), switch that change to Keep. Add any name the rules missed at the bottom. Then press Copy for Claude Code and paste it back.

The same name in other shows

A name found in one show's credits that also appears in a show whose own credits don't mention it. Usually the same handle (remove it); sometimes just an ordinary word, a band member or a song title (keep it). Distinctive names start as Remove, ordinary words as Keep.

Names the rules missed

One per line: a taper, uploader or site you spotted anywhere in the notes that should go too. They'll be added to the rules and removed wherever they appear.
